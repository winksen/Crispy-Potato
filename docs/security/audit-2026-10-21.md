# Security and performance audit, 2026-10-21

> **Scope:** the repository at `V0.1.33`: the `model`, `engine` and `cli` crates, the migrations, `scripts/db/roles.sql`, `scripts/checks/weekly.py`, the two workflows and the dependency tree. The planned API (track H) and web (tracks I–N) rows were read for design gaps, since neither is built.
> **Result:** 15 rows added to the [release index](../RELEASES_0.1.md): V0.1.34–V0.1.43 (track D2), V0.1.102, V0.1.104, V0.1.106, V0.1.107 (track H) and V0.1.146 (track N). Every planned row after them was renumbered. Two threats were added to the [threat model](threat-model.md) for the code as it stands (T25, T26) and two for the planned website and workflows (T27, T28).
> **Related:** [Threat model](threat-model.md) · [Release index](../RELEASES_0.1.md) · [SECURITY.md](../../SECURITY.md)

## Checked and sound

- **SQL** goes through `query!` and `query_scalar!` macros with bindings everywhere outside tests; offline metadata is committed and checked in CI.
- **Content loading** refuses symlinks and junctions before reading, caps file size and the YAML parser's budget, and re-validates the exact bytes it syncs from a private copy.
- **Secrets** are `SecretString`s, redacted in `Display` and `Debug`, marked sensitive in headers, read from bounded files, and never written into errors; HTTP errors carry no URL or body.
- **Responses** are capped at 20 MiB after decompression, parsed into types with serde_json's recursion limit, and cleaned before storage; one entity's failure never stops a run.
- **Transactions**: each entity's batch commits or rolls back whole, HTTP validators are stored only with the data they validated, and sync is one transaction under an advisory lock.
- **Roles**: the reader can't write, the writer can't run DDL or edit migration history, `PUBLIC` lost `CREATE` and `TEMP`.
- **CI** runs only on `pull_request` with a read-only token not kept in the checkout, and every action is pinned by SHA.
- **Compose** publishes Postgres on 127.0.0.1 only, and its password comes from an untracked `.env`.
- **No panics**: no `unwrap` or `expect` outside test modules, and `unsafe` is forbidden.
